# 使用教程

## 环境要求

- Python 3.10 或更高版本（推荐）

## 安装依赖

进入项目根目录后，执行以下命令安装所需依赖：

```bash
pip install -r requirements.txt
```

## 运行项目

安装完成后，运行主程序：

```bash
python main.py
```

如果使用 Windows 且安装了多个 Python 版本，可以使用：

```bash
py main.py
```
