# mirrorchromasonet

一个支持多格式导出的论坛文章镜像下载与阅读工具。

## ✨ 项目简介

mirrorchromasonet是一个用于论坛文章抓取、镜像保存、在线查看和多格式下载的工具。

支持将论坛文章转换为 **PDF、HTML、EPUB** 等格式，方便离线阅读、归档和分享。

## 🚀 功能特性

- 📥 **论坛文章下载**
  - 支持下载论坛帖子内容
  - 自动保存文章标题、正文、图片等信息

- 📖 **在线文章查看**
  - 内置文章阅读器
  - 支持浏览完整文章内容
  - 优化阅读体验

- 👤 **作者主页查看**
  - 支持访问作者主页
  - 快速定位相关内容

- 📚 **多格式导出**
  - PDF 文档下载
  - HTML 网页保存
  - EPUB 电子书格式导出

- 🌐 **多域名支持**
  - 支持多个论坛域名

## 📦 支持格式

| 格式 | 支持 |
| --- | --- |
| PDF | ✅ |
| HTML | ✅ |
| EPUB | ✅ |

# 使用教程

## 环境要求

- Python 3.10 或更高版本（推荐）

## 安装依赖

进入项目根目录后，执行以下命令安装所需依赖：

```bash
pip install -r requirements.txt
```

## 运行项目

安装完成后，运行主程序：

```bash
python main.py
```

如果使用 Windows 且安装了多个 Python 版本，可以使用：

```bash
py main.py
```
